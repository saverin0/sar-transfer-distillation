## What this means here

- Weights and code are under the Apache License 2.0 by every statement found - the card's
  front matter, the Hugging Face tag, the GitHub licence record, LICENSE.PE and the two
  README files. The statements agree.
- Apache 2.0 allows use, change and sharing under its conditions. It asks for its licence
  text and for marks on changed files. The copied code in
  `src/sartransfer/distil/teachers/vendor/pe/` carries LICENSE.PE as its LICENSE, every
  changed line is marked in place, and NOTICE.md there lists the changes with the hashes of
  the released and the copied files. The weights are not in the repository, they are
  downloaded once from the card at the pinned revision and checked by size and SHA-256.
- The Perception Encoder paper is arXiv 2504.13181 (Bolya and others, 2025). The card asks
  for a citation of it "if you find our code useful for your research".
- This file records what the pages said. It is not legal advice.
- Before anything is published the pages are read again, and a new dated file is written if
  one of them has changed.
